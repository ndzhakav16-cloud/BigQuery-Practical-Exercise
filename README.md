# Retail Sales BigQuery-Practical-Exercise
A SQL Practice Project using Google BigQuery

# Problem Statement

Retail companies rely heavily on transactional data to understand customer behavior, product performance, and revenue trends. 
This project provides hands-on SQL practice using a retail sales dataset on Google BigQuery, 
focusing on filtering, aggregation, grouping, conditional logic, and calculated fields.

# Aim of the Project

To practice essential SQL skills using Google BigQuery and generate insights from a Retail Sales dataset through structured query exercises.

# Objectives

This exercise will help to:
- Apply SQL filtering using WHERE and conditional statements.
- Use aggregate functions such as SUM, AVG, and COUNT.
- Work with GROUP BY and HAVING for grouped insights.
- Create new calculated fields using CASE.
- Use DISTINCT to identify unique values.
- Build analytical queries to gain insights from retail sales data.

# Tech Tools Used

- Google BigQuery (main SQL environment)
- SQL Standard Query Language
-  Sales Dataset (sample/learning dataset)
- Optional: GitHub for documentation
